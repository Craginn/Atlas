# What is “Improve the AI”?

`Improve the AI` is an optional setting within AI Dungeon that allows players to help us evaluate and improve how our various AI model versions are performing.

Opting into “Improve the AI” from your in-game settings helps us detect and fix issues to better the AI’s performance. If “Improve the AI” is turned on:

-   You will occasionally get a prompt to choose the best of multiple possible AI responses.
-   Model data, including inputs and outputs, will be logged anonymously and [may be published as part of an ongoing dataset collection project](https://help.aidungeon.com/dataset-publication-faq).

![icon](https://assets.super.so/311da5e0-9a02-4177-9f6a-b89435645aea/images/46905c7a-2771-48d7-a9bd-806c9ce7151c/settings.svg)

You can toggle this feature on or off by navigating to `Gameplay` → `AI Models` → `Testing & Feedback` through the gear icon in the top right corner of the game screen.
