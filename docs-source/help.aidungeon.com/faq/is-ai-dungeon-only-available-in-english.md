# **Is AI Dungeon only available in English?**

AI Dungeon is currently only available in English. We can't officially support more languages at this time due to the training set used for the AI as well as our own ability to support other UI languages as a small team.

That being said, some users reported that they have successfully played AI Dungeon in a few other languages—either by interacting with the AI directly in that language, or with the aid of translation software. With that in mind, you might want to try playing AI Dungeon in a different language and see how it goes!

If you have any feedback on your experience playing AI Dungeon in a language besides English, please add a post to the [bugs-feature-request channel on Discord](https://discord.gg/RcYntV44fF) or send an email to [support@aidungeon.com](mailto:support@aidungeon.com).
