# **I have an idea for a feature in AI Dungeon!**

We love any feedback from our players! To help us gauge interest in a potential feature, we encourage users to submit their ideas to the [bugs-feature-request channel on Discord](https://discord.gg/RcYntV44fF); please consider searching for similar requests and comment on those before posting the same request. Thank you!
