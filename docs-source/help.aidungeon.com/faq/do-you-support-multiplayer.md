# Do you support Multiplayer?

Yes we do! Multiplayer can be accessed a few ways:

### **Start a Multiplayer Game**

To start a new multiplayer game, open the `Play` menu, select `Multiplayer`, then `Create Game`. This goes to a Quick Start-like setup with various settings to choose from. After selecting one of these options, the game screen will load.

![image](https://assets.super.so/311da5e0-9a02-4177-9f6a-b89435645aea/images/158b7eb8-2c69-4709-8b6f-5c0e725a4055/Untitled.png?width=1600)

![image](https://assets.super.so/311da5e0-9a02-4177-9f6a-b89435645aea/images/89be8db8-3a9b-40a0-9b66-88bc49bae881/Untitled.png?width=1600)

![image](https://assets.super.so/311da5e0-9a02-4177-9f6a-b89435645aea/images/d4430ca1-e817-4e12-9388-dac7ef33cd08/Untitled.png?width=1600)

Opening up the game menu (flame icon) in the top left corner presents a new option: `Invite Players`! Select this to generate the eight digit join code, then share that with other players.

![icon](https://assets.super.so/311da5e0-9a02-4177-9f6a-b89435645aea/images/5cbe6d9e-fb72-43d0-85f9-d1da4d87f4cb/square-corner-line.svg)

**Remember:** anyone who has the code can join, so make sure you’re only sharing it with people you want to play with.

![image](https://assets.super.so/311da5e0-9a02-4177-9f6a-b89435645aea/images/5d437875-0142-42ea-b253-f20de8b58643/multiplayer2.png?width=1600)

After another player has joined your game, their avatar and name will show up in the game menu under yours! Selecting the three dots `···` next to their name gives you the option to `Kick` that player from the game or `Block` them completely. Only the host—whoever started the Multiplayer game—can Kick or Block other players.

![icon](https://assets.super.so/311da5e0-9a02-4177-9f6a-b89435645aea/images/888c7097-c94f-4bf4-ba4c-c33a0086d0d5/circle-x.svg)

**Kick** temporarily removes a player from the game, but they can rejoin. **Block** means a player can’t rejoin.

Currently, there is no set limit for how many people can join a Multiplayer game. The ‘(1/4)’ next to ‘Invite Players’ is simply a suggestion—Adventures can get a little crazy with overlapping actions when there are tons of people playing together! But that can also be part of the fun, so we’ve left this limitless for now and welcome feedback.

![image](https://assets.super.so/311da5e0-9a02-4177-9f6a-b89435645aea/images/62bee9de-3b4f-4755-8ae2-24b301944cdf/Untitled.png?width=1600)

Everyone’s avatar will also appear above the command buttons in the game screen, and when players Take a Turn, three dots will show up on their picture as they’re typing.

![image](https://assets.super.so/311da5e0-9a02-4177-9f6a-b89435645aea/images/412e5ed2-b08b-4482-823b-c6ebf20e8631/Untitled.png?width=1600)

**The host’s AI model settings will apply to all players who join a Multiplayer game. If the host has a premium membership, all players can benefit from the premium settings selected by the host.** We know this has been unclear in the past, so we’ve included specific language under popups in the game screen to ensure players are aware of how this works.

![image](https://assets.super.so/311da5e0-9a02-4177-9f6a-b89435645aea/images/224cec32-a92f-4a12-a694-298d251e1cc8/Untitled.png?width=1600)

### **Join a Multiplayer Game**

To join someone’s Multiplayer game, make sure you get the eight digit code from them, then open the `Play` menu, select `Multiplayer`, type or paste the join code, and select `Join Game`. You’ll go right into the game screen and can start playing!

To leave someone’s Multiplayer game, select the three dots `···` next to your name in the game menu. This brings up the options to `Edit Character Name` or `Leave`. Leaving the game is different from using `Exit Game` at the bottom of the game menu:

-   **Leave** removes you from the Multiplayer game. You will have to rejoin with the code to begin playing that game again.
-   **Exit Game** keeps you in the Multiplayer game and just takes you back to the home screen. You can select ‘Continue’ from the content card to keep playing.

![image](https://assets.super.so/311da5e0-9a02-4177-9f6a-b89435645aea/images/4a511bbf-2074-4d56-b304-65dcb4c763d6/Untitled.png?width=1600)

Once you’ve started or joined a Multiplayer game, those content cards will show ‘Multi’ instead of ‘Private’ or ‘Public’.

## FAQs

### **Can we use premium features in Multiplayer?**

Yes, only the host needs to have a premium subscription for all players to enjoy membership benefits during a Multiplayer game. So, if you want everyone to play using a Premium AI model, the player with a subscription should set up the Adventure.

### **Where can I find other people to play Multiplayer with?**

[On the Discord](https://aidungeon.com/discord) in the #multiplayer channel. You can talk to other players and find someone who wants to join a Multiplayer game!

Remember that **anyone who sees your short code will be able join the Adventure it came from**, so be careful who you share it with.

### **Can we play AI Dungeon in NSFW mode in Multiplayer?**

Yes, just make sure everyone participating is 18+ and all players are comfortable with NSFW content.

Because Multiplayer uses the host’s AI Model Settings, they control the [AI Safety Settings](https://help.aidungeon.com/faq/what-are-the-ai-safety-settings) as well. The host must change their safety setting to ‘Mature’ for everyone to play an NSFW game.

### Why use Third Person in Multiplayer?

Third Person perspective is primarily used for Multiplayer games because multiple characters are adding Do and Say inputs simultaneously. When this component is enabled from the [in-game settings](https://help.aidungeon.com/understanding-settings), everyone in the Adventure will be prompted to enter a name for their character, and that name will be used for their Do and Say actions.
